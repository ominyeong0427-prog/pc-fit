# FIT PC

부품 선택, 호환성 검사, 수치와 근거 기반 성능 평가를 제공하는 한국어 PC 구성 웹사이트입니다.

사이트: https://pc-fit-cart.ominyeong0427.chatgpt.site/

## 주요 기능
- 445개 제품: CPU 57개, GPU 102개, 메인보드 74개, 메모리 68개, SSD 39개, 케이스 61개, 파워 44개
- 제품 검색, 제조사 필터, 가격·제품명 정렬, 제품 더 보기
- 소켓·DDR 규격·메모리 용량·크기·간이 전력 기준의 호환성 검사 및 선택 차단
- 제품 사진, 치수, Three.js 기반 3D 모형, 판매처 검색 링크
- 지원 모델의 벤치마크 수치, 비교 대상, 출처, 테스트 조건을 포함한 장단점 평가
- 브라우저 장바구니 저장·복원, 구성 개수 배지, 견적 텍스트 다운로드

## 실행
HTML·CSS·JavaScript로 구성된 정적 사이트입니다. 빌드 과정이나 API 키가 필요하지 않습니다.
이 폴더를 정적 HTTP 서버로 제공하고 index.html을 여십시오. 제품 상세 페이지의 모듈·3D 기능은 HTTP 환경에서 실행해야 합니다.

## 사용 기술
HTML5, CSS3, Vanilla JavaScript, Three.js/WebGL, LocalStorage, SessionStorage.
제품 데이터는 catalog*.js, 치수 자료는 product-data.js, 정량 평가 근거는 evidence.js에 있습니다.

## 데이터 안내
가격에는 시연용 예시 가격과 일부 시점별 확인 판매가가 포함됩니다. 실시간 최저가 API는 연결되어 있지 않습니다.
장단점에 표시하는 외부 벤치마크는 리뷰 테스트 PC의 결과이며 선택한 전체 구성의 실측값은 아닙니다. 모델별 자료가 없으면 성능 우열을 판단하지 않습니다.
별도 게임 성능 화면의 FPS는 시연용 계산값입니다.
3D는 기본 도형으로 만든 모형이며, 확인된 치수를 비율에 반영합니다. 제조사의 정밀 CAD/스캔 데이터가 아닙니다.
호환성 검사는 등록된 자료 범위에 한정됩니다. BIOS·쿨러 간섭·전원 커넥터와 세부 장착 조건은 구매 전 확인해야 합니다.
장바구니는 현재 브라우저에 저장되며 서버 계정 간 동기화 기능은 없습니다.

## 출처
제품 사진·사양의 원본은 각 제품의 source 필드와 화면의 출처 링크를 참조하십시오.
정량 평가는 TechSpot, GamersNexus의 직접 테스트와 Adobe Premiere 공식 요구사항 등을 참고합니다.
제품 사진과 상표의 권리는 각 제조사 및 권리자에게 있습니다. 일부 제품은 시리즈 대표 사진을 사용합니다.
Three.js 등 외부 라이브러리의 라이선스 고지를 유지합니다.
