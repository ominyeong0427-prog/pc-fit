# FIT PC

224개 부품을 검색하고 PC 구성을 비교하는 한국어 정적 웹사이트입니다.

## 실행

이 저장소의 루트를 정적 웹 서버로 실행하세요. Python이 설치되어 있다면:

```sh
python -m http.server 8000
```

브라우저에서 http://localhost:8000 으로 접속합니다. 3D는 JavaScript 모듈을 사용하므로 파일을 직접 여는 대신 HTTP 서버를 사용해야 합니다. 별도 빌드나 API 키는 필요하지 않습니다.

## 주요 기능

- 부품 검색, 제조사 필터, 정렬, 이미지 카테고리 이동
- 구성 저장·복원·견적 다운로드 및 상세 페이지 왕복 시 선택 유지
- CPU 소켓, 메모리 규격·용량, GPU 길이, 파워 깊이와 전력의 기본 호환성 검사
- 확인된 규격 충돌 시 선택 차단, 미확인 높이·두께·쿨러·케이블 공간 경고
- 핵심 3줄 평가 및 게임별 예시 FPS
- 3D 상세 화면: 드래그 회전, 휠·핀치 확대/축소, 방향키와 +/- 키, Home으로 원래 보기
- 국내 판매처 6곳 검색 링크 및 확인된 해외 공식몰 가격 링크

## 데이터 범위와 한계

견적 합계와 FPS는 예시이며 실시간 최저가나 실측 벤치마크가 아닙니다. 3D는 카테고리 설명용 모형이며 실제 제품의 세부 외형·포트 위치를 재현하지 않습니다. 57개 제품에는 제조사 외형 치수 비율을 반영했습니다. 화면상 실물 1:1 크기는 아닙니다.

`product-data.js`는 2026-10-04 확인한 MSI 독일 공식몰 데이터입니다. 45개 제품에 해당 모델의 구매 가능한 옵션 중 최저 표시가를 EUR로 저장했습니다. 자동 갱신되지 않으며 국내 최저가 비교 결과가 아닙니다. 배송·수입세·한국 배송 가능 여부는 별도 확인해야 합니다. 미확인 가격은 숫자로 표시하지 않습니다.

장착 검사는 확인 가능한 규격에 한정됩니다. 케이스 외형 부피만으로 내부 공간이나 부품 간 간섭을 판정할 수 없습니다. 구매 전에 CPU 지원 BIOS, 쿨러 높이, 커넥터, 라디에이터와 케이블 공간을 확인하세요.

## 파일

- `index.html`, `shop.css`, `app.js`: 구성 화면과 호환성·성능 로직
- `product.html`, `product.css`, `product.js`, `viewer.js`: 제품 상세와 3D
- `catalog.js`, `photos.js`, `catalog-extra.js`, `catalog-legacy.js`: 카탈로그
- `product-data.js`: 출처·확인일이 포함된 제조사 치수와 판매가
- `images/`, `photos/`: 제품 이미지
- `vendor/`: Three.js 0.180.0과 MIT 라이선스

제품 이미지와 상표의 권리는 각 권리자에게 있습니다. 출처는 카탈로그 및 화면에 표시합니다. 일부 제품은 시리즈 대표 사진을 사용합니다.
