# FIT PC

사진으로 부품을 고르고 호환성과 성능 근거를 확인하는 PC 구성 웹사이트입니다.
사이트: https://pc-fit-cart.ominyeong0427.chatgpt.site/

## 주요 기능
- 7개 카테고리의 456개 제품 검색·필터·정렬
- 소켓, 메모리 규격, 등록된 장착 치수와 전력 조건에 따른 호환성 검사 및 선택 차단
- 제품 사진, 치수, Three.js 기반 3D 모형 및 판매처 링크
- 장점·제약을 나눈 성능 평가와 출처·테스트 조건을 포함한 게임별 FPS
- 장바구니 저장·복원·삭제, 중복 방지, 담은 구성 개수 표시

## 실행
HTML, CSS, JavaScript로 구성된 정적 사이트로 빌드나 API 키가 필요하지 않습니다.
Python은 로컬 정적 서버 용도이며 사이트의 백엔드가 아닙니다. 3D 모듈은 HTTP 환경에서 실행하세요.

## 주요 파일
- app.js: 선택·호환성·성능 평가
- catalog*.js, photos.js: 제품 카탈로그·사진
- product-data.js: 치수·판매처 정보
- benchmarks.js, evidence.js: 벤치마크 자료·비교 근거
- product.js, viewer.js: 상세 페이지·3D 모형
- cart*.js: 장바구니

## 데이터의 범위
가격은 예시 가격과 일부 확인 시점의 판매가이며 실시간 최저가 API는 없습니다.
게임 FPS는 외부 리뷰 실측 자료를 우선 사용하고, 비교 근거 기반 추정치와 참고 예시를 구분합니다. 자료가 없으면 수치를 제공하지 않습니다. 리뷰 테스트 PC는 선택한 전체 구성과 다를 수 있으며, 사용자의 전체 구성을 직접 측정한 결과가 아닙니다.
3D는 기본 도형으로 만든 모형이며 제조사의 CAD나 실제 제품 스캔이 아닙니다.
호환성은 등록된 자료 범위에서 검사하며 BIOS, 쿨러 간섭, 전원 커넥터 등은 별도 확인이 필요합니다.
장바구니는 현재 브라우저 LocalStorage에 저장되며 계정 간 동기화는 없습니다.
