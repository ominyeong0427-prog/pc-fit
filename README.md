# FIT PC

실제 부품 사진으로 PC를 구성하고 사양과 예시 성능을 비교하는 한국어 웹사이트입니다.

## 주요 기능

- 224개 부품 검색, 제조사 필터, 가격 정렬
- ‘나의 PC 구성’의 부품명으로 카테고리 이동
- CPU 소켓, DDR4/DDR5, 메모리 용량, 장착 길이, 전력의 기본 호환성 확인
- 전체 사양 안내, 핵심 3줄 요약, 펼쳐보는 게임별 예시 FPS
- 브라우저에 견적 저장 및 텍스트 다운로드

## 실행

압축을 풀고 `index.html`을 브라우저에서 열면 됩니다. HTML, CSS, JavaScript로 구성되어 별도의 빌드나 API 키가 필요하지 않습니다. 정적 웹 호스팅에서는 이 폴더를 사이트 루트로 사용하세요.

견적 저장은 브라우저의 로컬 저장소를 사용합니다. 파일로 직접 실행할 때 브라우저 정책에 따라 저장이 제한될 수 있습니다.

## 데이터 안내

가격과 FPS는 시연용 데이터이며 실시간 최저가 또는 실측 벤치마크가 아닙니다. 전체 성능 안내는 주요 사양에 따른 참고 평가입니다. 실제 구매 전 BIOS, 쿨러, 전원 커넥터, 제조사 지원 목록과 판매 여부를 확인하세요.

제품 이미지와 상표의 권리는 각 제조사 및 권리자에게 있습니다. 제품별 원본 출처는 카탈로그의 `source` 필드와 화면의 출처 링크에 기록되어 있습니다. 메모리 일부는 시리즈 대표 사진을 사용합니다.

## 파일

- `index.html`: 화면 구조
- `shop.css`: 스타일
- `app.js`: 선택·호환성·성능·견적 로직
- `photos.js`, `catalog-extra.js`, `catalog-legacy.js`: 제품 카탈로그
- `images/`: 제품 사진
